# MySQL Triggers – Banking Database

## Project Overview

A MySQL banking database mini project demonstrating **10 real-world trigger scenarios** for data validation, automated balance management, transaction auditing, and data integrity.

* **5 Related Tables**
* **100 Rows of Banking Data**
* **10 Trigger Scenarios**

## Database Tables

* `Customers`
* `Accounts`
* `Transactions`
* `Transaction_History`
* `Deleted_Accounts`

## Trigger Scenarios

1. Prevent zero or negative transaction amounts
2. Automatically update balance for deposits
3. Prevent withdrawals with insufficient balance
4. Automatically update balance for withdrawals
5. Record transaction history
6. Prevent transactions for inactive accounts
7. Prevent balance exceeding ₹1,00,000
8. Prevent withdrawals above ₹50,000
9. Store deleted account details for auditing
10. Prevent account deletion when transactions exist
